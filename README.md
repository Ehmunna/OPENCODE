📋 Requirements

- Android ARM64 Device

- Internet Connection
- Git, curl and tar

⚙️ Installation Guide

Step 1: Update Termux

pkg update && pkg upgrade -y

Step 2: Install Required Packages

pkg install git curl tar -y

Step 3: Clone Repository

git clone https://github.com/C04-wq/opencode-termux.git

Step 4: Open Project Directory

cd opencode-termux

Step 5: Run Installer

bash install.sh

Wait until the installation is complete.

🚀 Launch OpenCode

Start OpenCode anytime using:

opencode

🔍 Check Installed Version

opencode --version

🔄 Update OpenCode

cd ~/opencode-termux
bash install.sh

⚠️ Important Notes

- This installation method is designed for Android ARM64 devices running Termux.
- Node.js and npm are not required on your Android device.
- OpenCode is open-source software.
- AI model providers may have separate usage limits, API charges, or subscription requirements.
