📖 About

OpenCode Termux provides an installation method for running the OpenCode AI coding agent on Android devices through Termux.

It is designed for Android ARM64 users who want to use an AI-powered coding assistant without requiring root access or a computer.

✨ Features

- 🚀 Run OpenCode on Android ARM64
- 📱 No Root Required
- 💻 No PC Required
- ⚡ AI-powered coding assistance
- 🛠️ Interactive terminal interface
- 📦 Simple installation process
- 🔄 Easy updates

📋 Requirements

- Android ARM64 device
- Termux application
- Active internet connection
- Git, curl and tar

⚙️ Installation Guide

1. Update Termux

pkg update && pkg upgrade -y

2. Install Required Packages

pkg install git curl tar -y

3. Clone Repository

git clone https://github.com/C04-wq/opencode-termux.git

4. Enter Project Directory

cd opencode-termux

5. Run Installer

bash install.sh

Wait for the installation to complete.

🚀 Launch OpenCode

Start OpenCode anytime using:

opencode

🔍 Check Version

opencode --version

🔄 Update OpenCode

cd ~/opencode-termux
bash install.sh

⚠️ Important Notes

- This installer is intended for Android ARM64 devices running Termux.
- Node.js and npm are not required for this installation method.
- OpenCode itself is open-source software.
- AI model providers may have separate usage limits, API charges, or subscriptions.
- Review the installer script before executing it.
